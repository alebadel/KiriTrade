    Principles the agents wrote

    Each agent first wrote down the principles linking the evidence to its numbers, then applied them. These are the principles, grouped by wording, with the number of agents that wrote each.

      What this is, and is not

      What it is. The tracker’s partner-reported tuna series lags by months, and Thailand, the main importer, publishes latest. The nowcast fills the unpublished months with a baseline built from what has been published, and asks 30 AI agents to give their own view and to split it into Component A and Component B. Every agent receives the same evidence and the same instructions.

      How the baseline is tested. On a pseudo-real-time test over 86 months, using only what was known at each date, the baseline roughly halves the error of simply repeating the same month last year. Adding ship-tracking port arrivals did not improve it, so those signals are shown to the agents as context and are not part of the baseline.

      What it is not. It does not use Kiribati’s own trade or balance of payments figures, and it makes no claim that they are right or wrong. It is not an official estimate. The agents’ answers are not validated against an observed truth, because there is none to validate against. The comparable-country panel that would let the agents learn how other places’ figures are built is still empty, so today the principles rest on the standards texts and the model’s general knowledge.

      The method is in How the numbers are made.
